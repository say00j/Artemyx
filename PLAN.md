🚀 **Artemyx — MVP Development Plan**

Now that the exams are over, we'll start development. The goal for the first phase is to build a working **MVP (Minimum Viable Product)**.

The idea is simple: **if we complete the tasks below in order, we should have our first working version of Artemyx.**

### 🏗️ Phase 1 — Project Setup

- [ ] Set up React frontend
- [ ] Set up Node.js + Express backend
- [ ] Set up MongoDB database
- [ ] Connect frontend → backend → database
- [ ] Create basic project folder structure
- [ ] Set up Git branches and development workflow

### 🎨 Phase 2 — Basic UI

- [ ] Create navbar
- [ ] Create main dashboard layout
- [ ] Create sidebar/filter section
- [ ] Create reusable cards/components
- [ ] Create basic responsive layout

### 🗺️ Phase 3 — India Map

- [ ] Find/prepare India state GeoJSON data
- [ ] Display India map
- [ ] Display states on the map
- [ ] Add state hover information
- [ ] Add state click interaction
- [ ] Add basic heatmap coloring
- [ ] Add map legend

### 📊 Phase 4 — Crime Data

- [ ] Collect the required official crime data
- [ ] Decide the data structure
- [ ] Clean and normalize the data
- [ ] Insert sample data into MongoDB
- [ ] Create the final MongoDB collections
- [ ] Import the required MVP dataset

### ⚙️ Phase 5 — Backend API

- [ ] API to get all states
- [ ] API to get state crime statistics
- [ ] API to get district statistics
- [ ] API for yearly data
- [ ] API for crime-type filtering
- [ ] API for leaderboard/rankings
- [ ] Connect APIs to MongoDB

### 🏆 Phase 6 — State Rankings

- [ ] Create state leaderboard
- [ ] Display reported cases
- [ ] Calculate/display crime rate where appropriate
- [ ] Sort states by crime rate
- [ ] Connect leaderboard selection to the map
- [ ] Clicking a state opens its state dashboard

### 🏛️ Phase 7 — State Dashboard

- [ ] Display selected state
- [ ] Display state map
- [ ] Display district-level heatmap
- [ ] Create district leaderboard
- [ ] Display state statistics
- [ ] Allow clicking a district

### 🔎 Phase 8 — Filters

- [ ] Year filter
- [ ] Crime type filter
- [ ] State filter
- [ ] District filter
- [ ] Reset filters
- [ ] Make map, leaderboard and statistics update with filters

### 📈 Phase 9 — Basic Analytics

- [ ] Year-wise crime trend
- [ ] Crime category breakdown
- [ ] State vs India comparison
- [ ] District vs State comparison
- [ ] Basic charts

### 🧪 Phase 10 — Testing

- [ ] Test APIs
- [ ] Test database queries
- [ ] Test filters
- [ ] Test map interactions
- [ ] Test state/district navigation
- [ ] Test mobile responsiveness
- [ ] Fix major bugs

### 🚀 Phase 11 — MVP Release

- [ ] Final UI cleanup
- [ ] Verify data
- [ ] Deploy backend
- [ ] Deploy frontend
- [ ] Connect production database
- [ ] Test the deployed application
- [ ] Update README
- [ ] Release **Artemyx MVP 🎉**
